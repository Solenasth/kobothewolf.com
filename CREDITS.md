# Credits

Every asset this site publishes, and who holds its rights. `npm run validate` fails if an asset file is neither listed here nor licensed by a file next to it (DESIGN §7).

Published images carry pixel data only: any embedded metadata is stripped before they're committed (`scripts/strip-png.ts`).

## Meme-template art
The boykisser drawings are community meme templates whose authors deliberately stay anonymous, so no artist can be named. All rights stay with their original authors. Kobo cut them out as die-cut stickers (white border, flat pink shadow) and claims no ownership of them. Unknown-author fan art is not used ([decision 0003](docs/decisions/0003-public-repo-and-art.md)).

| File | What it is |
|---|---|
| `styles/boykisser-uwu/assets/st-licencia.png` | "Boykisser License UwU": the hand-drawn license card cat |
| `styles/boykisser-uwu/assets/st-feliz.png` | Happy face (eyes shut, open smile), from the boykisser sketch-sheet template |
| `styles/boykisser-uwu/assets/st-clik.png` | Boykisser at a keyboard, "\*CLIK\*" |
| `styles/boykisser-uwu/assets/st-yap.png` | Boykisser with a "UWU" laptop, "\*yap\* \*yip\*" |
| `styles/boykisser-uwu/assets/mascara-licencia.png` | Filled silhouette of the License cat, the mask the code-cat face fills with code |

If you hold the rights to one of these and want it credited differently or removed, write to contact@kobothewolf.com and it will be taken down.
